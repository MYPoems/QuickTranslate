# QuickTranslate v1.7.0

Windows x64 正式版本，支持从旧版覆盖升级。这一版合并了迭代计划里原定分四次发布的内容（计划中的 1.6.3、1.7.0、1.8.0、1.9.0）。

## 修复

- Word、Excel 和 Windows 11 记事本里划词提示“未检测到选中文字”：不再替用户注入“Alt 松开”，改为等快捷键松开后再复制。取词后恢复原剪贴板文本；原内容为图片、文件等非文本时不改动。
- 悬浮窗在前台且没有选区时按划词键，不再把上一次的译文重新翻译；取词失败时不再残留上一次的原文。
- OCR 开始识别后的内部错误在悬浮窗显示，不再停在“正在识别”。
- 单词释义返回的 JSON 带代码围栏或附带说明时能正确解析，不再把原始 JSON 当作译文显示并缓存。
- 历史搜索按字面匹配 `%` 和 `_`。
- OCR 错误信息遇到中文时可能崩溃的问题。

## 新功能

- **流式翻译**：句子和段落的译文边生成边显示。服务不支持流式时自动退回一次性请求。
- **更多语言**：新增日、韩、法、德、西、俄。可设置阅读的语言和译成的语言，悬浮窗菜单可为当前文本临时指定目标语言。
- **术语表与附加翻译要求**：只发送出现在原文里的术语。
- **手动输入翻译**：悬浮窗菜单或 `Alt + I`。
- **悬浮窗**：长原文默认折叠，最小尺寸也能看到译文；出错时给出下一步；固定状态重启后保留；进行中的识别或翻译可以取消。
- **设置页**：快捷键直接按键录入；校验不通过时显示具体原因并定位到字段；有未保存的改动时给出提示；所有分类共用一个保存按钮；云端 OCR 可测试连接。
- **首次使用引导**：尚未配置翻译服务时出现一次，可跳过。
- **截图**：超过云端上传上限的截图自动缩放；框选时显示尺寸；悬浮窗可重新框选。
- **历史**：滚动加载，按日期分组，支持键盘操作。
- **生词本**：每日复习上限按本机的自然日统计（此前在东八区是早上 8 点重置）；显示今日进度；复习可全程用键盘。

## 升级时会发生的变化

- **API Key 与服务地址绑定**。升级后首次启动，原来保存的翻译、OCR、朗读 Key 各自归属到当时配置的服务地址，继续可用。之后换到另一个服务地址需要为它单独填写 Key，换回来时原来的 Key 仍在。旧的凭据条目保留不删。
- **翻译历史与缓存分开保存**。首次启动时把原有记录拆入独立的历史表，保留编号、时间和收藏。历史保留最近 5000 条，收藏不计入也不被清理；“清理缓存”不再删除历史。
- **旧的翻译缓存不再命中**（缓存键加入了服务地址、术语表和附加要求），同一段文字升级后第一次会重新请求模型；历史记录不受影响。
- 设置文件的格式版本不变。升级后如果再装回 1.6.2，语言、术语表和附加要求这几项设置在旧版保存设置时会丢失；历史表和 Key 的归属旧版不认识，建议降级前先备份。
- 应用内更新在安装前照常备份设置、窗口尺寸和两个数据库。

## 验证情况

本节在发布后更新过。发布时这个安装包还没有在任何机器上安装运行过；下面第四项是发布当天补做的。

已验证：

- GitHub Actions（Windows、MSVC、Node 22）上前端构建与测试、Rust 格式检查、Clippy、Rust 测试通过。
- 取词用仓库里的回归驱动在记事本、Word（正文与表格）、Excel（单格、多格、编辑态）上用合成文档测试，全部取到文字，焦点不变，原剪贴板恢复。
- 隔离模式的调试构建（不读真实凭据、不注册快捷键）里核对了悬浮窗、设置页、生词本的真实窗口画面。
- 发布后（2026-11-13）在一台机器上从 v1.6.2 覆盖安装了这个安装包并验收，详见[本机安装验收](../V1.7.0-LOCAL-INSTALL.md)：
  - 升级的数据保留：旧记录全部拆入历史表，逐行比较完全一致；生词本、设置、窗口尺寸和 OCR 插件前后一致；翻译、云端 OCR、云端朗读三个旧 Key 都归属到了当前服务地址，旧条目保留。
  - 真实的 `Alt + Q`：记事本、Word 新建文档、Excel 单个单元格里都取到文字并用真实的翻译服务译出，原剪贴板恢复；无选区时给出提示和“手动输入”。

发布后发现的问题：

- 应用启动后第一次按截图快捷键，选区遮罩一闪就关闭，要按第二次。相关代码自 v1.6.2 起没有改动，不是这一版引入的。已在 [v1.7.1](v1.7.1.md) 修复。

没有验证：

- 悬浮窗的拖动、缩放、点击窗口外收起和固定。
- 框选识别与云端 OCR、朗读。流式翻译的显示过程和首段耗时没有测量；缩放后截图的识别效果未测。
- 历史页、生词本复习、设置页的保存与连接测试、手动输入、指定目标语言、术语表。
- 应用内更新路径（验收时是用脚本覆盖安装的）、全新 Windows 用户环境下的安装和首次使用引导。
- 浏览器及其他程序里的取词、非 Alt 的自定义快捷键、原剪贴板为图片或富文本时的表现。

如果升级后 Key 显示未配置，在设置里重新填写即可；遇到历史异常，可从 `upgrade-backups` 里的备份恢复。
## 安装

普通用户只需下载安装包，无需 Git、Node.js、Rust 或 Visual Studio。安装命令及哈希校验见仓库 README。

- 安装包：`QuickTranslate_1.7.0_x64-setup.exe`，19,652,373 字节（约 18.74 MiB）。
- SHA-256：`A5D8109543DB43DE82994539017618E37FF1D90717B8155473FBC88F517D0D26`。
- 附安装包更新签名、`SHA256SUMS.txt` 和应用内更新使用的 `latest.json`。
- 安装包在本机用 GNU 工具链构建并用既有的更新私钥签名；构建前 60 项前端测试、133 项 Rust 测试通过，签名绑定 1.7.0 且篡改后的包被拒绝。

Tauri 更新签名用于验证安装包，不是 Windows 商业代码签名。SmartScreen 可能显示“未知发布者”，请只从本仓库 Releases 下载并核对 SHA-256。
