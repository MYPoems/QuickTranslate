# v1.2.1 本机验证记录

本轮不创建 GitHub Release，也不修改在线更新源。云端朗读默认开启选项，但未配置独立 Key 不会发起请求；不使用现有翻译/OCR 密钥。

## 已通过

- 前端 19 项测试：短首段、单段预生成、失败和取消、PCM 首块到达即就绪、暂停/恢复、停止后丢弃迟到音频、默认云端及离线选择 UI。
- Rust 67 项常规测试、格式检查与 Clippy；5 项依赖真实环境/下载/签名的测试默认忽略。
- 本地 WebSocket 模拟服务验证鉴权请求、音频先于完成事件交付、同连接复用、内存缓存、停止取消；不访问生产语音服务。
- 旧 Schema 3 升至 Schema 4，默认云端，保留离线音色、语速、双语偏好及其他设置；版本备份与重复加载通过。设置、历史、收藏备份和迁移测试继续通过。
- 隔离 QA 应用启动，真实 Windows 设置窗口的控件状态确认：默认云端、北京地域、`qwen3-tts-flash-realtime`、中英文 `Cherry`、独立 Key 未配置提示。未输入真实密钥。
- 单独执行安装插件只读测试：Windows x64 GNU debug 构建，Kokoro INT8 v1.1、sherpa-onnx 1.13.8、4 线程。冷启动中文短句约 22.3 秒；复用模型后的另一中文短句约 6.3 秒；英文短句约 5.5 秒；同内容缓存约 4 毫秒。取消测试清理工作进程。数字仅代表本机这些测试句，不代表正式构建或任意文本性能。
- 对 GNU release 正式构建重复同一工作进程测试：冷启动约 8.2 秒，热中文约 4.3 秒，英文约 3.8 秒，缓存约 3 毫秒，取消通过。此测试还验证了无控制台窗口的正式二进制可以使用匿名管道；仍不是云端延迟或扬声器端到端性能。
- 最终 NSIS 安装包 18.46 MiB，通过 Minisign 签名、版本绑定与篡改拒绝测试，仅本机覆盖安装。安装后应用文件/产品版本均为 1.2.1，后台进程正常；已安装二进制与构建产物仅差 Tauri 官方 NSIS/未知安装类型标记的 3 字节。
- 已安装版本再次通过插件只读测试：冷中文约 7.7 秒，热中文约 4.3 秒，英文约 3.8 秒，缓存约 4 毫秒，取消通过。
- 覆盖安装前在 `%LOCALAPPDATA%/QuickTranslateLocalBackups/` 备份旧应用及设置/SQLite WAL；安装后使用明确路径的普通 Python 运行只读审计，46 条历史、0 条收藏的内容摘要与备份完全一致，SQLite 完整性检查通过；原有设置、离线音色偏好及窗口尺寸保留，朗读方案为云端。未删除原插件，未导出凭据。

## 限制与用户验收

- 未配置专用云端 Key，尚未实测阿里云生产接口首声延迟、真实声音播放及长段落网络中断。WebAudio 播放逻辑有自动化测试，但不等同于实际扬声器验收。
- 在设置中填写与北京/新加坡地域匹配的专用 Key，点击测试连接，再保存；测试显示收到首音频块耗时，不是实际扬声器出声时间。
- 手动验证中文、英文、双语跟读、暂停/恢复、连点重播、关闭窗口停止及断网错误提示。测试连接与朗读可能产生云端费用。
- 切回离线，确认原音色仍在；连续两段应复用模型，停止后允许下次重新加载；闲置约 5 分钟释放。
- 第三方语音库许可证需在公开分发前复核，进程隔离不豁免 GPL 相关义务，见[音色插件说明](SPEECH-PLUGIN.md)。
- GNU 链接器仍报告既有的 `.rsrc` 多 manifest 警告，未阻止签名安装及启动；正式公开发布仍建议按 README 使用 MSVC 工具链并在干净 Windows 环境验收。

接口依据：[阿里云实时语音合成](https://help.aliyun.com/zh/model-studio/qwen3-tts-flash-realtime)、[客户端事件](https://help.aliyun.com/zh/model-studio/qwen-tts-realtime-client-events)、[服务端事件](https://help.aliyun.com/zh/model-studio/qwen-tts-realtime-server-events)。
