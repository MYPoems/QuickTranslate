# 未固定悬浮窗拖动与失焦收起修复

## 范围

- 基线 `64fd513`，保留本轮前序收藏页与透明圆角修复。
- 移除拖动空白区的 `title`，不再显示“按住鼠标左键拖动悬浮窗”悬停提示；保留无障碍名称和普通箭头光标。
- 不修改原生 `data-tauri-drag-region`、拖动 capability、边缘缩放、窗口大小保存逻辑或固定状态。
- 本阶段未覆盖安装版；后续按用户要求以 v1.6.2 完成本机覆盖安装，见 [本机安装验收](V1.6.2-LOCAL-INSTALL.md)。未发布 Release。

## 原因与处理

原失焦处理将未固定窗口的所有 `Focused(false)` 直接当作离开窗口。当前 Tauri/Wry 的 Windows 实现会把 WebView `LostFocus` 转为窗口失焦事件；原生 `WM_ENTERSIZEMOVE` 又会转移 WebView 焦点，因此仅凭这个事件无法区分拖动/缩放和真正切换到其他窗口。

处理失焦事件时，额外使用 Windows `GetForegroundWindow` 和 `GetAncestor(GA_ROOT)` 核对原生前台窗口：

- 悬浮窗仍是前台窗口：保留显示，即使 WebView 临时失焦。
- 前台窗口已是其他窗口：未固定且未打开收藏页时正常收起。
- 固定或收藏页打开：沿用原有保护。
- 无法获取原生窗口/前台窗口：不凭不确定结果立即收起。

只在失焦事件到来时查询，不增加计时器、拖动轮询、全局鼠标钩子或额外依赖。

## 手动验收

1. 在 QuickTranslate QA 窗口点击图钉取消固定。
2. 在顶部文字与按钮之间的空白区域按住左键并移动，确认窗口移动且不会消失。
3. 悬停该区域，确认无文字提示且仍为普通箭头。
4. 拖动任意边缘或角落改变大小；再次拖动标题空白区，确认两个行为互不影响。
5. 点击其他窗口，确认未固定时正常收起。固定后重复点击外部，确认保留显示。

本页明确区分逻辑/构建检查、原生观察与人工移动验收，不以浏览器模拟替代 Windows 长按拖动。
