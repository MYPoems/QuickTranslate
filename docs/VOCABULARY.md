# 生词本 v1.5.0

## 收藏与词卡

悬浮窗的“收藏单词”使用选中的英文词（OCR 文本框也可选择），单词翻译时也可直接收藏。“选取生词”从英文原文/译文列出候选，每次最多 20 个。大写缩写不自动列出，可手动填写。最长 48 字符，可有内部连字符/撇号；主要覆盖英文词，不拆分短语。

去重按小写词形，不盲目将 saw 等歧义词强制归一。模型建议的基本词形在词卡内由用户确认：已有目标词则合并来源并保留目标进度；无目标词则重新生成词卡，防止屈折词形题目沿用旧答案。

词卡包含 word、lemma、ipaUk、ipaUs、partOfSpeech、definitions、contextMeaning、examples、collocations、quizzes。英美 IPA 不确定时留空。词卡/题目是 AI 内容，不能视为权威词典。支持编辑，编辑后重新学习；改变词义应同时核对题库或显式更换题目。

沿用当前翻译 Provider、Base URL、Model 与 Windows Credential Manager 的翻译 Key。本机端点可以无 Key。缓存键绑定词形、来源句、端点、模型与提示版本；仅发送该词和一条必要来源句，不上传整个历史或词库。重新生成会产生新请求；无自动收费重试。并发上限 2，失败保留草稿。最多 5000 词、每词 20 条来源，模型响应最多 64 KiB，词卡最多 32 KiB。

## 学习与复习

- 首次学习立即可用，但不计三次复习。
- 默认最短间隔 4 小时，允许 4–168 小时；降低设置不提前解锁旧计划，延长设置延后尚未到期计划。
- 到期复习先隐藏释义，用户回忆后翻面。“记得”增加一次，“模糊”不增加，“忘记”退一步，下次仍等待完整间隔。
- 提前查看、朗读、关闭窗口、换页不计复习；每日上限默认 20（1–100，按 UTC 日，所有复习评分计入）。
- 第三次成功后再等待一次间隔才可测试，最早 16 小时完成。已掌握词归档，不自动永久删除。

例：首次学习 08:00；第一次最早 12:00，第二次 16:00，第三次 20:00，测试最早次日 00:00。实际按 Unix 时间，不受本地日期显示格式影响。

## 测试

第一题选择语境释义，作答后隐藏第一题进入拼写填空。Rust 按缓存题库判分，拼写只忽略大小写及首尾空白，不接受无关近义词。两题同时正确才归档。答案不在测试专用响应中返回，但本机词卡/备份题库包含答案；这是自用学习工具，不是防作弊考试系统。

失败回退 2/3；等待完整间隔复习后再等待完整间隔测试。缓存至少两组题并交替使用，选项轮换；“题目有问题”或退出不计失败，可显式付费更换题目而保留复习进度。题目会话最长 24h，关闭窗口取消；编辑/重学使旧会话失效。

后端验证到期、词卡版本、操作标识、重复提交和每日上限。检测超过 5 分钟的系统时间回退并拒绝计次；离线系统不能防止人为将时间向前调，也不声称能防作弊。

## 数据与升级

生词本独立保存于应用数据目录 `vocabulary.sqlite3`，不属于可淘汰翻译缓存，清空翻译历史不影响词卡。Schema 1；未来 Schema 拒绝打开，不降级覆盖。SQLite WAL/FULL，迁移/安装前备份包含词卡、事件和测试数据，备份失败不开始安装。

JSON 包含词卡、上下文、进度、复习事件、测试记录和词形别名，不含 API Key。合并导入需确认，不覆盖同名现有词条；导入空库还恢复规则。已进行中的测试不会恢复为活动会话。备份可能含私人阅读内容，请自行保管。CSV 有 UTF-8 BOM、转义公式，仅阅读，不用于还原进度。

永久删除需明确确认，不可从“已掌握”自动触发；误删可从先前 JSON/安装备份恢复。重学保留词卡及来源，进度重新开始。

## 开发验证

`npm test` 含前端收藏/复习/测试/导入交互；Rust 测试覆盖精确间隔、幂等提交、失败回退、每日上限、时间回退、恢复、WAL 备份及模型协议。调试版独有 `QUICKTRANSLATE_QA_DIR` + `QUICKTRANSLATE_QA_VOCABULARY=1` 可启动隔离数据和 loopback 模型。此模式不编入正式版，不读取真实 Key、不注册全局快捷键。
