# QuickTranslate v1.7.2

Windows x64 补丁版本，支持从旧版覆盖升级。不改变设置、历史、生词本或插件的数据格式。

## 修复

- 云端 OCR 换成通用视觉模型（如 `qwen4-max`）后报“Parameter min_pixels must be greater than or equal to 4096”。

  原因：每个 OCR 请求都给图片带着 `min_pixels: 3072` 和 `max_pixels: 8388608`，这是阿里云百炼专用文字提取模型（`qwen3.5-ocr`、`qwen-vl-ocr`）的取值，通用视觉模型的下限不同。现在只对专用文字提取模型发送这两个参数，其他模型只收到图片和指令。带了附加参数的请求被 HTTP 400 拒绝时，会去掉它们、只带图片再发一次。

- 从悬浮窗点“打开设置”“打开生词本”“重新框选截图”时，如果对应的窗口还没有打开过，弹出的是一个空白窗口。

  原因：这几个命令是同步命令，在悬浮窗的回调里新建窗口，Windows 上新窗口的网页视图建不出来。现在改为异步命令。“打开生词本”自 v1.5.0 起、另外两个自 v1.7.0 起有这个问题；从托盘菜单和快捷键打开不受影响。

- 服务返回 HTTP 403 时一律显示“API Key 无效”。

  阿里云百炼在模型的免费额度用完且开启了“免费额度用完即停”时返回 403，这时 Key 并没有问题。现在会直接说明是免费额度用完；其他 403 显示服务端的原话。

- 无法通过 OpenAI 兼容接口使用 Claude。

  原因：应用发送的 `temperature: 0.1` 会被 Claude 4.7 及之后的模型以 HTTP 400 拒绝。现在对 Claude 模型不发这个字段。

## 改进

- **阿里云百炼的新模型更快**：百炼的现行模型（如 `qwen3.8-flash`、`qwen4-max`）默认先“深度思考”再回答，查词和截图识别会因此变慢并多消耗 Token。现在对百炼地址的请求会关闭它。模型不接受这个开关时自动去掉重试，并在本次运行内记住。专用文字提取模型的请求保持不变。
- **新图标**：一个同时是放大镜的“Q”，镜片里两行文字，白色是原文、琥珀色是译文。此前用的是 Tauri 的默认图标。
- **服务商预设**：阿里云百炼的默认模型由 `qwen-turbo` 改为 `qwen3.8-flash`；新增 Anthropic Claude（`https://api.anthropic.com/v1`，`claude-haiku-5-5`）。已保存的设置不受影响。

选哪个模型、阿里云百炼免费额度的规则，见仓库 README 的“选哪个模型”一节（注明了查阅日期和来源）。

## 验证情况

这个安装包在发布之前先装到了一台机器上，用真实服务验收过，详见[本机安装验收](../V1.7.2-LOCAL-INSTALL.md)。

已验证：

- GitHub Actions（Windows、MSVC、Node 22）上前端构建与测试、Rust 格式检查、Clippy、Rust 测试通过。
- 请求的形状有单元测试；用本机回环 HTTP 服务重放了“min_pixels must be greater than or equal to 4096”这条报错，第一次带参数被拒绝，第二次只带图片并成功。
- 在真实的阿里云百炼服务上：
  - 真实 `Alt + Q` 划词，用 `qwen3.8-flash` 译出。
  - 设置页“测试连接”，`qwen3.8-flash`：连接成功。
  - 设置页“测试云端 OCR 连接”，`qwen3.8-flash`：连接成功，1033 ms；`qwen4-max`：连接成功，1849 ms。后者就是此前以 `min_pixels` 报错拒绝请求的模型。
- 从悬浮窗“更多 → 打开生词本”打开的窗口有完整的内容；修复前同样的操作得到的是空窗口。
- 重启应用后第一次按 `Alt + W`，遮罩保持显示，Esc 能关闭，别的窗口到前台时收起。
- 程序文件、窗口标题栏和托盘里显示的是新图标。
- 从上一个已安装版本覆盖安装后，历史、生词本、设置和窗口尺寸保留。

没有验证：

- 框选屏幕区域做真实的 OCR 识别：只做了连接测试（上传的是内置的小图片）。
- Claude：没有用 Anthropic 的服务试过，不发 `temperature` 这条规则只有测试覆盖。
- 关闭“深度思考”带来的速度差别没有测量；只确认了带着这个开关的请求被上面两个模型接受。
- 模型拒绝附加参数后自动重试、403 的新提示，在真实服务上都没有被触发过。
- 应用内更新路径（验收时是用脚本覆盖安装的）、全新 Windows 用户环境。

- 安装包：`QuickTranslate_1.7.2_x64-setup.exe`，19,679,070 字节（约 18.77 MiB）。
- SHA-256：`1B430850A551DD4CE3597EDAD5F3A3C39CCC6C7E46C53B44C545CBDB13E75739`。
- 附安装包更新签名、`SHA256SUMS.txt` 和应用内更新使用的 `latest.json`。
- 安装包在本机用 GNU 工具链构建并用既有的更新私钥签名；构建前 61 项前端测试、151 项 Rust 测试通过，签名绑定 1.7.2 且篡改后的包被拒绝。
