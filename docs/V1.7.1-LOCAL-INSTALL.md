# v1.7.1 本机安装验收

2026-11-13，在 v1.7.1 公开发布之后进行。安装的是 Release 里的同一个安装包（SHA-256 `4349F065596580676F24612B6CC843D7A4E2FB37C6A7DE6DB377298BA8BBC86D`），从 v1.7.0 覆盖安装。不公开用户的记录数量、内容、备份编号和凭据。

## 安装与数据

- 用 `scripts/install-local.ps1` 加了 BOM 的副本运行（原因见 [v1.7.0 的验收记录](V1.7.0-LOCAL-INSTALL.md)）。脚本核对哈希，备份程序、设置、窗口尺寸和两个数据库并写入 `COMPLETE.txt`，再静默覆盖安装并启动。安装前 1.7.0 没有在运行，原因不明，系统日志里没有它的崩溃或无响应记录。
- 安装后运行中的程序路径不变，产品版本为 1.7.1。
- 安装前后各用 SQLite 在线备份做一份快照并比较，随后删除了临时副本：`scripts/audit-history.py` 和 `scripts/audit-vocabulary.py` 都报告内容一致、完整性 `ok`。
- `settings.json` 和 `popup-window.json` 的 SHA-256 前后相同；凭据管理器里 QuickTranslate 的条目数量不变（只看条目，不读内容）。

## 截图遮罩的修复

v1.7.1 唯一的改动。用脚本重启已安装的应用，等 8 秒，再注入真实的 `Alt+W`，每 20 毫秒观察遮罩窗口是否可见。没有拖动选区，没有保存画面。做了两轮，每轮都重启应用。

| 步骤 | 第一轮（按住约 80 毫秒） | 第二轮（按住约 300 毫秒） |
| --- | --- | --- |
| 启动后第一次按键 | 148 毫秒出现，2.5 秒后仍显示 | 20 毫秒出现，2.5 秒后仍显示 |
| 此时遮罩是前台窗口 | 是 | 是 |
| 按 Esc | 关闭 | 关闭 |
| 第二次按键 | 立即出现并保持 | 立即出现并保持 |
| 另一个窗口到前台（测试打开的记事本） | 遮罩收起 | 遮罩收起 |

第二轮里脚本主动把记事本切到前台的那一步报告未成功，但遮罩已经收起：记事本启动时自己到了前台。两轮结束时遮罩都已关闭。

对照：同样的方法在 1.7.0 上三次重启，第一次按键遮罩都在出现后几十毫秒内消失或没有被观察到。

## 划词冒烟

在新开的记事本里全选一句合成的英文，注入真实的 `Alt+Q`：取到原文，译文正确，原剪贴板文本恢复，Esc 收起悬浮窗。文本发给了已配置的翻译服务。
