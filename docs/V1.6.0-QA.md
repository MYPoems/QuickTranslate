# v1.6.0 界面迭代验收

本轮仅本地源码与隔离测试，不推送 GitHub、不发布 Release、不替换用户安装版。
开发分支 `codex/v1.6.0-ui`，稳定基线 `c0a576c` / `codex/v1.5.0`。

## 已实现

- 悬浮窗：复制译文 + 更多上拉菜单；原文、译文各自的小喇叭，再次点击停止；OCR 编辑后显式重译。
- 去除外围留白、底层阴影及 Windows 无边框窗口的额外白边，仅保留一层 14px 圆角卡片。
- Memo 浅色 / 深蓝灰主题、跟随系统；通用 → 外观提供 0–30% 背景透明度，文字、按钮、展开菜单保持不透明。
- 设置分类导航；学习规则独立保存。API Key 仍保存在系统凭据中。
- 生词本、历史统一双栏比例与圆角；单词、来源句、例句及其译文、历史原文 / 译文均有独立朗读入口。
- 保留学习间隔、复习计次、测试、归档、编辑、备份、收藏和搜索；次要操作折叠。
- 历史可从 SQLite 缓存直接打开到悬浮窗，不请求模型；删除和清空需确认。

- `npm run build`：通过。既有可选 PP-OCR 依赖仍有浏览器模块外置及大资源包警告，未在本轮扩大改动。
- Rust：93 项通过、5 项需外部音色 / 下载 / 签名环境的测试按原配置忽略；Clippy `-D warnings` 与格式检查通过。
- 配置 schema 4 → 5：保留旧模型、OCR 引擎和音色，保存原始迁移备份，重开幂等；外观配置持久化、范围校验及旧设置备份导入均覆盖。
- SQLite 历史按 ID 读取缓存并保留完整翻译结果，已删除记录不可再次打开；学习数据库和历史清理仍互不影响。

## Windows 原生隔离检查

使用 debug 专用 `QUICKTRANSLATE_QA_DIR`，配置、SQLite 与临时凭据均在隔离目录，不访问用户 API Key。
已拉起原生设置与 OCR 夹具悬浮窗；透明度改为 30% 保存后重启保持，原文 / 译文仍可辨识，更多菜单保持不透明，Esc 首先关闭菜单。
原生窗口显式设置全透明底层背景，避免 WebView2 的白色底层；禁用 Windows shadow，移除其额外 1px 白边。
测试进程与临时 Vite 服务结束后关闭；测试夹具数据保留。未重测真实云端延迟、PP-OCR 下载或正式安装器流程。

## 回退

当前用户安装版未改动。源码回退需先提交 / 备份工作区，然后 `git switch codex/v1.5.0`，不使用破坏性 reset。
若将来安装后需要降级，先备份当前设置、两个 SQLite 数据库及 WAL/SHM；旧版本拒绝更高 schema，需使用对应升级前完整备份或 `settings.pre-v4.json`，不要直接覆盖新版本用户数据。
