# QuickTranslate v1.7.1

Windows x64 补丁版本，支持从旧版覆盖升级。只有一处修复，不改变设置、历史、生词本或插件的数据格式。

## 修复

- 应用启动后第一次按截图快捷键（默认 `Alt + W`），选区遮罩出现一瞬间就自己关闭，要按第二次才能框选。

  原因：遮罩窗口在第一次按键时才创建，显示时焦点会从窗口移到内部的 WebView，窗口在 1 毫秒内先后收到“获得焦点”和“失去焦点”，而它其实仍在最前面。旧逻辑把这次失焦当成离开遮罩并把它隐藏。现在只有别的窗口到了前台才收起遮罩；无法判断前台窗口时照样收起，避免全屏遮罩误留在最上层。

  相关代码自 v1.6.2 起没有改动，所以这个问题不是 v1.7.0 引入的，更早的版本应当也有；没有在 v1.6.2 上实测。

## 验证情况

已验证：

- GitHub Actions（Windows、MSVC、Node 22）上前端构建与测试、Rust 格式检查、Clippy、Rust 测试通过。
- 隔离模式的调试构建（不读真实凭据、不注册快捷键）冷启动后自动打开两次遮罩：第一次打开保持显示并且是前台窗口，按 Esc 能关闭；第二次打开保持显示，把另一个窗口切到前台后遮罩自动收起。
- 判定规则有三项单元测试。

没有验证：

- **这个安装包发布前没有在任何机器上安装运行过。** 修复没有在安装版里用真实快捷键验证过。
- 上面的遮罩验证跑的是“修复加临时跟踪日志”的构建；发布的代码去掉了日志调用，只跑了单元测试和全量检查。
- 遮罩打开后按 Win 键、Alt + Tab、锁屏等其他离开方式。
- 框选识别本身，以及 v1.7.0 发布说明和[本机安装验收](../V1.7.0-LOCAL-INSTALL.md)里列为未验证的其他内容。

## 安装

普通用户只需下载安装包，无需 Git、Node.js、Rust 或 Visual Studio。安装命令及哈希校验见仓库 README；Release 附安装包更新签名、`SHA256SUMS.txt` 和应用内更新使用的 `latest.json`。

Tauri 更新签名用于验证安装包，不是 Windows 商业代码签名。SmartScreen 可能显示“未知发布者”，请只从本仓库 Releases 下载并核对 SHA-256。
