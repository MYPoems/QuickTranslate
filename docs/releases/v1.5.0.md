# QuickTranslate v1.5.0

本地构建与安装验收版本，不上传 GitHub，不发布公开 Release，也不修改公开更新订阅。

- 从划词/OCR 翻译中收藏单个或多个英文生词；独立生词本、保留来源句、确认词形合并。
- AI 音标、释义、例句、搭配与缓存题库；沿用翻译模型和朗读配置。仅在明确收藏/生成时调用模型，失败保留草稿。
- 至少 4 小时间隔的三次复习与两题测试，通过归档到“已掌握”，支持重新学习和确认永久删除。
- JSON 进度备份与合并导入、CSV 阅读导出；SQLite WAL 备份及迁移保护。

AI 词卡与题目需核对。云端生产 Key 的实际质量、费用和朗读延迟不在模拟验收证明范围内。
