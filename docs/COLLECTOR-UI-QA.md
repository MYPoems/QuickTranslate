# 收藏页样式与悬浮窗暗角修复

## 范围与基线

- 基线为 v1.6.1 / `c1724b1`，开发分支 `codex/collector-ui-fix`。
- 仅调整收藏对话框的布局、样式和选词数量反馈，不修改数据库、收藏/生成流程、朗读、快捷键或原生拖动/缩放设置。
- 本轮为源码修复和隔离验收，不覆盖本机正式安装版，也不发布 Release。

## 改动

- 与悬浮窗共用深浅主题颜色、14px 圆角、图标和按钮风格；收紧标题与间距。
- 固定标题和底部操作栏，内容区独立滚动；来源句与详细说明默认折叠，费用及 AI 内容核对提示仍保留。
- 显示已选数量，手动输入与候选词相同词形去重；支持取消、关闭按钮和 Esc，取消不会发起收藏或模型生成。
- 原生 `dialog::backdrop` 是覆盖整个 WebView 的矩形，曾把窗口四个透明圆角涂暗。悬浮窗收藏对话框保留透明原生 backdrop，用圆角卡片内部的裁切遮罩实现暗化；仍使用原生 modal 焦点隔离。
- 生词本普通窗口中的收藏对话框仍使用原有普通遮罩，不改变全局 dialog 样式。

## 验证

- 类型检查、前端生产构建和 38 项前端测试通过。构建保留原有可选 OCR/OpenCV 的外部模块及大块体积警告，本轮未变更其打包结构。
- 浏览器 QA：8 组尺寸 × 深浅主题，悬浮窗 520×380 / 360×180；收藏页边界、长单词换行、计数、说明展开、内容滚动、底栏固定、焦点留在 modal 和 Esc/取消通过。
- PNG 透明像素检查覆盖打开前、打开时和关闭后四个角；强制恢复旧矩形 backdrop 的负对照会重现不透明暗角，恢复新样式后四角透明。
- 生词本普通收藏页验证原生遮罩仍为 `rgba(0, 0, 0, 0.4)`，无候选词时隐藏空选词区。
- GNU Windows Debug 构建成功；实际 WebView2 隔离窗口检查深浅主题的收藏布局、圆角和关闭恢复。深色窗口额外检查内容滚动及展开来源句时标题/操作栏保持固定。
- Rust 测试 93 项通过，5 项外部环境依赖测试沿用原有忽略设置；本机 GNU 链接保留既有 multiple manifests 警告，不能视作 MSVC 构建验收。
- 使用全新 `QUICKTRANSLATE_QA_DIR`、内存 QA 凭据和演示文字，不读取真实 API Key 或修改用户设置、历史、生词本；未测试真实云端生成和正式安装升级。
