# v1.6.1 · 清爽界面与悬浮窗拖动

- 顶部中间空白区域支持按住鼠标左键并移动来拖动悬浮窗，无需等待固定时长。
- 拖动区域避开标题、固定/关闭按钮和窗口边缘；保留边缘/角落缩放及尺寸记忆。
- 修复缺少 Tauri 启动拖动权限的问题，新增权限仅授权本地悬浮窗。
- 包含 v1.6.0 界面迭代：Memo 浅色/深蓝色主题、背景透明度、分类设置、独立小喇叭、精简更多菜单及双栏生词本/历史。
- 包含此前本机迭代的云端 OCR、云端流式朗读、可选离线插件、生词收藏、模型词卡缓存、间隔复习和掌握测试。

Windows x64 安装包支持覆盖升级。升级前备份用户设置、历史和生词本；保留原有配置、API Key 与已安装插件。安装包附 SHA-256、Tauri 更新签名与 `latest.json`。

Tauri 更新签名用于校验安装包，并非 Windows 商业代码签名。Windows SmartScreen 可能显示“未知发布者”；请仅从本仓库 Releases 下载并核对 SHA-256。
