# QuickTranslate v1.2.0

本次集中完善“截图 → 云端 OCR → 修正原文 → 翻译 → 朗读”的轻量工作流。

- 原文、译文分别朗读；暂停、继续、停止和重新播放。
- 分段高亮，自动匹配中英文音色；支持按原文、译文顺序双语跟读。
- 语速与中英文音色偏好持久化，编辑 OCR 原文后朗读修正后的内容。
- 关闭悬浮窗、开始新翻译或编辑原文时停止旧朗读；连续点击不叠音。
- Windows 本机离线语音，不需要朗读 API、不上传朗读内容。音色缺失时有明确的语音包安装提示。
- 一键安装可选 Kokoro 中英文离线音色插件，约 164 MiB；含六种精选音色，支持进度、取消、完整性校验和卸载，无需管理员权限。
- 新安装默认推荐云端 OCR；升级保留用户原有 Windows、PP-OCR 或云端选择，不自动上传离线截图。
- 应用内检查、下载进度、取消下载、签名和版本校验，以及用户二次确认安装。
- 安装前自动备份设置、悬浮窗尺寸与 SQLite 历史（包含收藏和 WAL 中的数据）；备份失败阻止安装。
- 旧设置升级至 Schema 3，保留原始版本备份，拒绝降级覆盖未来版本设置。

## 升级注意

v1.0.0 没有应用内安装能力，首次升到 v1.2.0 需要下载安装包并覆盖安装；以后可在设置中的“应用更新”执行确认式升级。覆盖安装保留用户数据及 Windows 凭据管理器中的 API Key。

当前机器若缺少英文或中文系统音色，可在应用“设置 → 离线朗读”主动一键安装中英文插件，或在 Windows“时间和语言 → 语音”安装系统语音包。应用不会擅自安装 Windows 系统组件。

更新包使用 Tauri/Minisign 签名；这与 Windows 商业代码签名不同。安装程序仍可能显示 SmartScreen“未知发布者”，请从本仓库的 Releases 下载，并核对 SHA-256。
