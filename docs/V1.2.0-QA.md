## 实际界面

使用仅 Debug 提供的隔离 QA 模式：单独临时数据目录，内存凭据，不注册真实快捷键，不修改真实开机启动。

- 原生 WebView 展示 OCR 原文及译文、朗读按钮、播放状态和当前段落高亮。
- 验证中文音频实际播放状态、第一段到第二段切换、编辑原文后实际使用新文字、暂停/继续/停止与恢复编辑。
- 英文音色当前未安装，正确展示语音包安装提示。英文有音色情况下的真实发声仍需在对应 Windows 环境验收；队列逻辑与语言音色路由已自动测试。
- 设置页显示云端优先方案、语速、中文与英文音色选择，检测到本机系统音色。
- 热重载后原生窗口选择句柄恢复失败，停止后续原生输入；不将其算作应用功能通过。
