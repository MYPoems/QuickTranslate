# QuickTranslate v1.6.2

Windows x64 正式补丁版本，支持从旧版覆盖升级。

- 收藏页统一悬浮窗主题、圆角、图标和紧凑布局，固定标题/操作栏，内容独立滚动；来源句说明可折叠，显示已选数量。
- 修复打开收藏页时矩形遮罩涂暗悬浮窗四个透明圆角的问题。
- 修复未固定悬浮窗把原生拖动/缩放的 WebView 临时失焦当作离开窗口的问题；真正切换到其他窗口仍会收起。
- 移除顶部空白拖动区的文字悬停提示，保留普通箭头光标、原生拖动与边缘缩放。
- 不修改配置、历史、生词本或插件数据格式；安装前备份原程序和用户数据。
