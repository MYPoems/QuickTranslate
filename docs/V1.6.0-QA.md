# v1.6.0 界面迭代验收

本轮已完成本地源码、隔离测试与用户授权的安装版替换；不推送 GitHub、不发布 Release。
开发分支 `codex/v1.6.0-ui`，稳定基线 `c0a576c` / `codex/v1.5.0`。

## 已实现

- 悬浮窗：复制译文 + 更多上拉菜单；原文、译文各自的小喇叭，再次点击停止；OCR 编辑后显式重译。
- 去除外围留白、底层阴影及 Windows 无边框窗口的额外白边，仅保留一层 14px 圆角卡片。
- Memo 浅色 / 深蓝灰主题、跟随系统；通用 → 外观提供 0–30% 背景透明度，文字、按钮、展开菜单保持不透明。
- 设置分类导航；学习规则独立保存。API Key 仍保存在系统凭据中。
- 生词本、历史统一双栏比例与圆角；单词、来源句、例句及其译文、历史原文 / 译文均有独立朗读入口。
- 保留学习间隔、复习计次、测试、归档、编辑、备份、收藏和搜索；次要操作折叠。
- 历史可从 SQLite 缓存直接打开到悬浮窗，不请求模型；删除和清空需确认。

## 回退

源码回退需先提交 / 备份工作区，然后 `git switch codex/v1.5.0`，不使用破坏性 reset。
安装版降级前先退出应用并另行备份当前设置、两个 SQLite 数据库及 WAL/SHM，防止丢失升级后的新增记录。旧版本拒绝更高 schema；可使用上述升级前完整备份恢复程序与对应数据，或针对设置使用 `settings.pre-v4.json`，不要直接覆盖新版本用户数据。
